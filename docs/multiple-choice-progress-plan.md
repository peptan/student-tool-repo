# 進数変換：4択化と学習到達状況の再設計

## 解決する問題

- 基本情報技術者試験に合わせ、自由入力を4択へ置き換える。
- 正解した設問も含め、採点後は全問の正答・解説を開いた状態で表示する。
- 「全試行の正答数 / 全試行数」を、元の10問に対する理解度として表示しない。

## 学習記録の単位

変換方向ごとに、問題を開始した時点の10問を「学習セット」とする。

- **初回の成績**：その10問を最初に解いた成績。例 `1 / 10問`
- **復習の成績**：直近の復習セットの成績。例 `1 / 9問`
- **到達状況**：元の10問のうち、一度以上正解した問題数。例 `2 / 10問（20%）`
- **未正解**：元の10問のうち、一度も正解していない問題数。例 `8問`

したがって、初回 `1/10`、復習 `1/9` の経過では「到達状況 2/10（20%）」を主表示とし、`2/19（11%）` は表示しない。

## 保存範囲

ブラウザのローカルストレージに、変換方向ごとの10問セット、正解済み問題キー、初回・復習の成績、未正解問題だけを保存する。氏名、任意入力、外部送信は行わない。

## 受入条件

1. 各問題に正解を含む4つの選択肢があり、選択肢は重複しない。
2. 採点後は正解・不正解に関係なく10問すべての解説が表示される。
3. 初回1/10、復習1/9の状態で、到達状況が2/10（20%）、未正解8問になる。
4. 2/19（11%）のような混合割合を主画面に表示しない。
5. 実ブラウザで、4択選択・採点・復習・メニュー表示を確認する。

## 検証ログ

- 自動確認：`npm test`（12件成功）、`npm run check`、`git diff --check` を実行。
- ローカル実ブラウザ：4択10問、正解を1問選んだ初回採点（1/10）、全10問の解説展開、9問復習で1問正解後の到達状況（2/10・20%）と未正解8問、メニュー上の初回/復習成績分離を確認。コンソールエラーなし。
