# 進数変換：学習記録の単純化

## 決定

復習機能・誤答リスト・セット到達状況を廃止する。学習記録は変換方向ごとの解答数・正解数だけをブラウザ内に保存する。

## 表示

- 問題の採点後：`○ / 10問 正解` と全問の解説を表示する。初回・今回・到達・未正解という表記は使わない。
- メニュー：全体と変換方向ごとの `正解数 / 解答数` と正解率を表示する。
- 分析：全体の「解いた問題」「正解」「正解率」と、変換方向ごとの正解率だけを表示する。

## 保存の移行

既存バージョン4の変換方向別初回集計は、復習を混ぜていないため、新しい通算の正解数・解答数として引き継ぐ。誤答リスト・セット・問題キーは引き継がない。

## 受入条件

1. メニューに復習ボタン・誤答数・到達状況がない。
2. `quiz.html?mode=review` はメニューへ戻る。
3. 採点後に全問解説が出る。
4. 40問中7問正解の既存記録は、全体 `7 / 40問（18%）` として表示される。
5. 方向別・全体の正解率は、解いた問題だけを分母にする。

## 検証ログ

- 自動確認：`npm test`（12件成功。40問中7問正解の移行・集計を含む）、`npm run check`、`git diff --check` を実行。
- ローカル実ブラウザ：4択10問の採点結果（2 / 10問 正解）、全問解説、復習URLからのメニュー復帰、メニューの `2 / 10問 正解（20%）`、分析画面の全体・変換別正解率、コンソールエラーなしを確認。
