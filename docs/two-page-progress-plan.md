# 旧・2ページ化と学習記録（廃止）

> 復習・到達状況を含む旧仕様です。現在は `docs/simple-learning-record-plan.md` の単純な正解数・正解率仕様へ移行済みです。

## 目的

1. 最初は変換方向を選ぶメニュー画面だけを見せる。
2. 変換を選んだ後に問題・採点・解説の画面へ遷移する。
3. このブラウザだけに正答数・出題数・誤答問題を保存し、変換ごとの正解率と誤答復習を提供する。

## 画面フロー

`index.html（変換メニュー・学習記録）` → `quiz.html（問題・採点・解説）` → `index.html`

- メニューは6方向のカード。カードを選ぶと、その方向だけの新規10問を `quiz.html` で開始する。
- 「間違いを復習」は保存済みの誤答から最大10問を開く。正解した誤答は復習リストから取り除く。
- 問題画面の「メニューへ戻る」は採点せずにメニューへ戻る。

## ローカル保存の範囲

`localStorage` の `student-tool.base-converter.progress.v1` に以下だけを保存する。

- 変換方向ごとの出題数・正解数
- 再復習用の誤答問題（数値、ビット幅、変換方向、正答、固定解説）

氏名、学籍番号、入力した誤答文字列、外部送信、アクセス解析は保存しない。

## 受入条件

- 初期URLでは問題を表示せず、変換カードと学習記録を表示する。
- 選択した変換の問題だけが10問出題される。
- 採点後に変換別の正解率が更新され、再読込後も残る。
- 不正解問題は復習へ現れ、復習で正解すると一覧から消える。
- ブラウザ外への通信は行わない。

## 検証ログ

- 実装後（ローカル `http://127.0.0.1:4173/`）：メニュー画面の6方向カード、問題画面への遷移、選択方向だけの10問、採点結果、変換別の正解率（1 / 10問）、誤答9問の復習画面を実ブラウザで確認。
- 自動確認：`npm test`（9件成功）、`npm run check`、`git diff --check` を実行済み。
- ブラウザコンソール：ローカルのメニュー・問題・誤答復習画面でエラーなし。
