# student-tool-repo

生徒公開用の情報学習ツールです。個人情報・ログイン・外部送信を使わず、ブラウザ内だけで動作します。

## 1個目: 進数変換 10問チャレンジ

`apps/base-converter/index.html` をブラウザで開くと、2進数・10進数・16進数の変換問題をランダムに10問出題します。

- 10問を一度に表示し、最後にまとめて採点
- 各問で正答・入力値・固定形式の式を表示
- **もう一度10問**で新しい問題セットを生成
- 回答や履歴は保存・送信しない

### 出題範囲

基本情報技術者試験の科目Aにある「基礎理論／数値表現」を意識し、過去問で頻出の**基数変換そのもの**に絞ります。

| 難易度 | 範囲 |
|---|---|
| 基礎 | 4ビット（0〜15）の2進数・10進数・16進数 |
| 標準 | 8ビット（0〜255）の2進数・10進数・16進数 |
| 発展 | 12ビット（0〜4095）の2進数・10進数・16進数 |

- 2進数→16進数は右から4ビットずつ区切る方法を解説します。
- 16進数→2進数は1桁を4ビットへ置き換える方法を解説します。
- 2進数→10進数は各桁の重み（`2^n`）を足す方法を解説します。
- 10進数→2進数は2で割り、余りを下から読む方法を解説します。
- 符号付き整数、補数、小数、負数、浮動小数点は別ツールに分けるため、この版の対象外です。

過去問本文・選択肢の転載はしていません。公式の出題範囲に合わせてオリジナル問題を毎回生成します。
