# student-tool-repo

生徒公開用の情報学習ツールです。個人情報・ログイン・外部送信を使わず、ブラウザ内だけで動作します。

## 1個目: 進数変換 10問チャレンジ

`apps/base-converter/index.html` を開くと、最初に変換方向を選ぶメニューが表示されます。選択後は `quiz.html` の問題画面へ遷移し、その方向だけの問題をランダムに10問出題します。

- 各問は正解を含む4択。採点後は正解・不正解を問わず全問の解説を表示
- 変換ごとの「初回の成績」「直近の復習の成績」「10問に対する到達状況」を分けて、この端末のブラウザ内だけに保存
- **間違いを復習**で、未正解の問題を最大10問出題。正解すると復習リストから外れる
- 新しく10問を開始すると、その変換の到達状況を新しいセットとして記録
- 個人情報・任意入力・回答履歴は保存・送信しない

### 出題範囲

基本情報技術者試験の科目Aにある「基礎理論／数値表現」を意識し、過去問で頻出の**基数変換そのもの**に絞ります。

| 難易度 | 範囲 |
|---|---|
| 基礎 | 4ビット（0〜15）の2進数・10進数・16進数 |
| 標準 | 8ビット（0〜255）の2進数・10進数・16進数 |
| 発展 | 12ビット（0〜4095）の2進数・10進数・16進数 |

- 2進数→16進数は右から4ビットずつ区切る方法を解説します。
- 16進数→2進数は1桁を4ビットへ置き換える方法を解説します。
- 2進数→10進数は各桁の重み（`2^n`）を足す方法を解説します。
- 10進数→2進数は2で割り、余りを下から読む方法を解説します。
- 符号付き整数、補数、小数、負数、浮動小数点は別ツールに分けるため、この版の対象外です。

過去問本文・選択肢の転載はしていません。公式の出題範囲に合わせてオリジナル問題を毎回生成します。

## ローカル確認

依存パッケージは不要です。

```bash
cd /Users/agent/workspace/student-tool-repo
npm test
npm run check
open apps/base-converter/index.html
```

## 構成

```text

├── index.html          # 変換を選ぶメニュー・学習記録
├── quiz.html           # 問題・採点・解説の画面
├── styles.css          # 画面デザイン
├── menu.js             # メニューと正解率表示
├── quiz.js             # 出題・採点・復習画面
├── progress-store.js   # ローカルストレージの学習記録
├── base-converter.js   # 出題・採点・解説の純粋ロジック
└── tests/
    ├── base-converter.test.js
    └── progress-store.test.js
```
